# Przykład przekazania zadania do Symphony

1. Przygotuj zwykłe zadanie PLAT: opisz oczekiwaną zmianę i sprawdzalne kryteria akceptacji.
2. Rozwiąż zależności oznaczone relacją Blocks przed przekazaniem zadania.
3. Przenieś zadanie do statusu W toku; etykieta agent-ready nie jest wymagana.
4. Oczekuj jednego otwartego PR po testach, niezależnym review i wymaganym CI oraz statusu Weryfikacja w Jira.
5. Merge i wdrożenie wymagają osobnego działania operatora.

Na początek cztery projekty korzystają z jednego wspólnego pipeline’u; Mac musi być włączony.
